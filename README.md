# Delta Shorts Studio

**给「三角洲竖屏动画」用的 AI 短视频生产管线。** 目标：把一条视频的生产成本压到「15 分钟人工 + 可复用资产」，并让产能随资产库增长而线性上升。

同时作为 a16z **HAA（Horowitz Andreassen Academy）** 申请的核心 PoW：重点不是单条爆款，而是**一套可复制、可度量、带合规追踪的生产系统**。

---

## 管线分层

```
① 素材层   assets/          固定资产库：角色 / 场景 / 道具 / 特效 / 音频 / 模板
                          每条资产带来源与风险等级（二创路线的刹车）
        ↓
② 剧本层   spec/storyboard  分镜 JSON：镜头、时长、字幕、配音、音效、素材引用
        ↓
③ 生成层   tools/gen        图像/动画生成（本地 RX 6750 GRE 12GB + 关键镜头走云）
        ↓
④ 合成层   tools/compose    生成「剪映专业版草稿」→ 你在剪映里预览导出
        ↓
⑤ 发布层   （人工）          你上传抖音、挂车、看数据 → 回流到分析表
```

## 关键选型：为什么不用 ffmpeg

本机 **ffmpeg 未安装**，但**剪映专业版已安装（11.5.0.14471）**。

所以合成层**不碰 ffmpeg**：直接生成剪映的 `draft_content.json`，你在剪映里预览、微调、导出。好处有三：

1. 剪映本身就是抖音的原生工具，导出参数与上传链路最顺；
2. 你能在时间线上手动改，不必等我改代码；
3. 省掉一整套编码依赖，换机也能跑。

## 合规设定（二创路线的刹车）

素材路线已确定为「游戏录屏 / 素材二创」。这条路起量快，但有两个真实风险，管线里用机制处理，而不是靠自觉：

| 风险 | 管线里的对策 |
| --- | --- |
| 腾讯 IP：游戏画面/角色/UI 用于**商业变现**（带货、收益）比纯二创风险高一档 | 每条资产在 manifest 里记录 `ipOwner` / `licenseStatus` / `commercialUse`；分镜里标记 `riskNote`；发布前跑一次风险汇总 |
| 抖音 AIGC 规范：不得用未授权他人肖像/声音，且 AI 内容需标识 | 生成内容默认打 AI 标识；不使用真人肖像/声音克隆；导出前检查清单 |

**边界（我不会越过的线）**：不导出、不打包、不转售游戏本体素材（模型/贴图/音频原文件）。二创成片可以发，**素材本身不能当商品卖**。带货的商品必须是第三方正规商品（书、AI 模型、素材包等），不是游戏素材。

## 我需要你做的两步

1. **给我一个剪映草稿样本**（约 30 秒）
   打开剪映 → 新建草稿 → 随便拖一张图或一段视频进时间线 → 加一行文字 → 保存 → 关闭剪映。
   然后告诉我一声，我直接读 `draft_content.json` 的真实结构。
   *（不这么做我只能猜格式，而猜错的代价是整轮返工——已经在别处栽过两次。）*

2. **GitHub token**
   本机**没有 `gh` CLI、也没配 git 身份**，所以「GitHub 权限开放」目前落不了地。需要你给一个 PAT：
   - 经典 token：勾 `repo`（+ `workflow` 若要用 Actions）
   - 或 fine-grained：`Contents: Read and write`、`Pull requests: Read and write`，限定到一个新仓库

   **发我时请直接贴，用完我会写进 `.env`（已加 `.gitignore`），不写进任何提交。**

## 目录规划

```
studio/
├─ README.md                    本文件
├─ spec/
│  ├─ asset-library.md          固定资产库规范
│  └─ storyboard.schema.json    分镜 JSON Schema
├─ assets/                      固定资产库（图片/视频/音频/模板）
│  └─ manifest.json             资产索引 + 来源与风险追踪
├─ projects/                    单个视频项目（分镜 + 引用）
├─ tools/                       生成与合成脚本
├─ out/                         成片与草稿输出（不进版本库）
└─ data/                        账号数据回流（播放/完播/转化）
```
